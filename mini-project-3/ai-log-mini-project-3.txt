Throughout this project, I used Claude in a few different ways to help me build and review my HTML and CSS. I used it to trim down the Bootstrap navbar code from the class slides, nest the “You Might Also Like” cards correctly, and double check my jumbotron. Claude was especially helpful when building the hero jumbotron and checking the accessibility and responsive design of my page. During these checks, I learned a few new skills to help improve my code. For example, I learned how to use @media queries to change the hero section’s image size and padding on larger screens because the image was not displaying correctly on smaller screens. I also used Claude to troubleshoot an issue with my footer, where one of my social media icons was getting pushed outside its container. Claude explained how to use flex-wrap: wrap so the icons would move to a new line if there was not enough space. Additionally, during the keyboard accessibility check, I learned how to use the focus selector alongside the existing hover selector to make links more accessible. I was already familiar with the hover selector, which changes the appearance of a link when someone moves their mouse over it, but I learned that adding the focus selector provides a similar visual cue when someone navigates to the link using the Tab key. This helps make the page easier to navigate for people who use a keyboard instead of a mouse. Overall, I used Claude to explain new concepts, troubleshoot layout issues, and check my work for accessibility and responsiveness throughout the project.
